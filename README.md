# combinational-logic-circuits-in-verilog
A collection of fundamental combinational digital circuits designed and implemented using Verilog HDL in Xilinx Vivado, including Half Adder, Full Adder, 4-to-1 Multiplexer, and 4-bit Ripple Carry Adder. This project documents my hands-on learning and practice of digital logic design, Verilog HDL, and simulation using Vivado.
